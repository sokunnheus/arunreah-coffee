# អរុណរះ កាហ្វេ · Arunreah Coffee

គេហទំព័រផ្លូវការរបស់ **អរុណរះ កាហ្វេ (Arunreah Coffee)** — ហាងកាហ្វេពិសេសនៅក្រុងសៀមរាប ប្រទេសកម្ពុជា។

## ✨ លក្ខណៈពិសេស (Features)
- ☕ **ម៉ឺនុយសម្បូរបែប (Comprehensive Menu):** ជាង ៤០ មុខ ចែកជា ៦ ប្រភេទ (កាហ្វេ, ភេសជ្ជៈពិសេស, តែ/ម៉ាចឆា, ស្មូធី, នំ, អាហារសម្រន់)
- 📱 **Mobile-First Experience:** មាន Mobile Bottom Navigation Bar និង Slide-Over Drawer Menu ដូចកម្មវិធីទូរស័ព្ទដៃ (Native Mobile App)
- 🎨 **ពុម្ពអក្សរខ្មែរស្រស់ស្អាត (Khmer Typography):** រៀបចំឡើងដោយប្រើពុម្ពអក្សរ Moul, Battambang, និង Noto Sans Khmer យ៉ាងច្បាស់ត្រជាក់ភ្នែក
- 🌓 **Dark / Light Mode:** ប៊ូតុងប្តូរពន្លឺ រក្សាទុកតាម localStorage
- 📅 **ប្រព័ន្ធកក់តុ (Table Booking System):** បង្កើតសារកក់តុស្វ័យប្រវត្តិ ចម្លងចូល Clipboard និងភ្ជាប់ទៅ Telegram ភ្លាមៗ
- 🎁 **Pop-up ប្រូម៉ូសិន ៥ វិនាទី (5-Second Promo Modal):** បង្ហាញការផ្តល់ជូនពិសេសដោយរលូន និងស្រស់ស្អាត

## 🚀 បច្ចេកវិទ្យា (Tech Stack)
- Semantic HTML5
- Modern CSS3 (Responsive Design, CSS Variables, Glassmorphism)
- Vanilla JavaScript (Pure JS, Lightweight, Super Fast)
